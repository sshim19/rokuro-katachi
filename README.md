# ろくろの形

左の親指でろくろのまわりをなぞって土の中心を保ち、右の親指は細い棒の端を持って、先で土を削り、今日の見本に近づけるゲームです。同じ日は、だれが遊んでも同じ見本です。携帯は横向きで、両手で遊びます。

## 遊び方

1. 画面を横向きにして、「はじめる」を押します。制限時間は70秒です。
2. 左の親指でろくろのまわりをなぞって回します。土の脇に指を寄せると、中心が収まります。右の親指は棒の端を持っていて、棒の先は指の左上にあります。先を土に当てると削れ、深く当てるほど細くなり、上へなぞると背が伸びます。マウスなら、片方ずつ動かすことができます。
3. 速さが安定して中心が出ていると、形がきれいに整います。振れたまま削ると、ゆがみが残ります。
4. 18秒を過ぎれば「仕上げ」で早めに確定しても構いません。時間が来ると、そのときの形で仕上がります。

最高記録と、その日の最高記録は、この端末に保存されます。0点は記録しません。

終了画面の X と LINE のボタンから、いまの得点をそれぞれの投稿画面で共有できます。

## 開き方

ビルドは不要です。フォルダをウェブサーバーで公開するか、手元では次のように開きます。

```bash
python3 -m http.server
```

ブラウザで `http://localhost:8000/` を開いてください。`file://` では動きません。
